## 5. 后续建议（评审关注点）

1. **决策点 R-001 · mysql-connector-j 必要性**：pom.xml 引入了 MySQL 驱动，但 `application.yml` 无 mysql profile，疑为其他模块误带入。建议在 Sprint 2 收尾前明确移除或新增 mysql profile。
2. **决策点 R-002 · 错误码 §16.6 编号清理**：RFC §16.6 与 §3.13 表中"INVALID_REQUEST"未列入 9 个错误码清单，但 `GlobalExceptionHandler` 已实现并测试通过。建议 §16.6 表中显式追加"INVALID_REQUEST / HTTP 400"以保持文档与代码一致。
3. **决策点 R-003 · Sprint 2 收尾是否需拆 PR**：9 个 TASK 可拆 2-3 个 PR（沙箱 + Controller/Feign + springdoc），建议 PR1 = TASK-1.2.1~1.2.5，PR2 = TASK-1.3.1~1.3.4。
4. **决策点 R-004 · 限流粒度**：TASK-3.2.2 在 Sprint 4，与 §3.5 Controller 不在同一 Sprint；建议评估"Controller 入口先用最简 IP 限流兜底，Sprint 4 再替换为细粒度限流"。
