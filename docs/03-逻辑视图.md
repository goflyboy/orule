## 3.3 SimpleTS 编译器模块（核心新增）

> 这是连接"业务人员写规则"和"引擎执行规则"的关键桥梁。W1 必须先搭骨架。

```
infrastructure/simplets/
├── SimpleTSParser.java          # facade：parse(source, meta) → SimpleTS-AST
├── SimpleTSValidator.java        # 白名单校验 + DomainMeta 字段校验
├── SimpleTSASTConverter.java     # SimpleTS-AST → TS-AST（运行期 IR）
├── GroovyCodeGen.java            # TS-AST → Groovy 脚本字符串
├── DRLCodeGen.java               # TS-AST → Drools DRL（cruleengine 兼容）
└── DecisionTraceGen.java          # 每个 AST 节点带行号 → JSON trace
```

**输入**：SimpleTS 源码字符串 + DomainMeta（元数据）
**输出**：SimpleTS-AST（内部表示） + TS-AST（运行期 IR） + Groovy 脚本 + 决策日志 schema

**编译链路**（与 SimpleTS.md §10 一致）：

```
SimpleTS 源码
  │ parse (TypeScript Compiler API + 白名单剪枝)
  ▼
SimpleTS-AST（内部表示）
  │ transform (语义提升 + 行号映射)
  ▼
TS-AST（运行期 IR）
  │ codegen
  ▼
{ Groovy 脚本, DRL 规则, 决策日志 JSON }
```

**MVP 关键决策**：W1 先实现 `parse + GroovyCodeGen`，其他生成器后续迭代。

## 3.4 SPI 插件体系（4 类）

### SPI-1：展现态插件（PresenterPlugin）

| 实现 | 代码 | 优先级 |
|------|------|--------|
| NaturalLanguagePresenter | `nl` | 🔴 P0 |
| TablePresenter | `table` | 🔴 P0 |
| SimpleTSSourcePresenter | `simplets` | 🔴 P0 |
| TSJsonPresenter | `ts-json` | 🟡 P1（只读调试用，不作为主编辑视图） |

```java
public interface PresenterPlugin {
    String getCode();
    String getDisplayName();
    // 渲染（给前端看）
    String render(String simpleTSOrAstJson);
    // 解析（用户编辑后保存）
    String parseFromUserInput(String userInput, DomainMeta meta);
    // 导出到 SimpleTS（统一中间态）
    String toSimpleTS(String formData, DomainMeta meta);
    // 从 SimpleTS 导入
    String fromSimpleTS(String simpleTS, DomainMeta meta);
}
```

### SPI-2：执行引擎插件（EnginePlugin）

| 实现 | 代码 | 优先级 |
|------|------|--------|
| GroovyEnginePlugin | `groovy` | 🔴 P0 |
| CruleEngineAdapterPlugin | `cruleengine` | 🔴 P0 |
| JsEnginePlugin | `js` | 🟡 P1（dry-run/单测用） |

```java
public interface EnginePlugin {
    String getCode();
    String getDisplayName();
    boolean supports(String formType);  // 支持 SimpleTS（语义层中间态）
    ExecutionResult execute(EngineRequest request);
    default List<String> healthCheck() { return List.of(); }
}
```

### SPI-3：转换器插件（ConverterPlugin）

| 实现 | From | To | 类型 |
|------|------|-----|------|
| NlToSimplets | NL 文本 | SimpleTS 源码 | LLM_BASED |
| SimpletsToTable | SimpleTS 源码 | 表格 JSON | AST_TREE |
| TableToSimplets | 表格 JSON | SimpleTS 源码 | AST_TREE |
| SimpletsToNl | SimpleTS 源码 | NL 文本 | LLM_BASED |

> **转换架构约束（ADR-009）**：
> - **NL ↔ SimpleTS** 是 LLM_BASED（必须调用 LLM）
> - **Table ↔ SimpleTS** 是 AST_TREE（纯结构化转换，性能高、确定性）
> - **不存在** NL ↔ Table 直接转换、NL → Groovy/DRL 直接转换
> - SimpleTS → TS-AST、Groovy、DRL 是**编译**（不是转换），不归 ConverterPlugin 管

```java
public interface ConverterPlugin {
    String getFromForm();   // "nl" | "table" | "simplets" | "ts-json"
    String getToForm();
    ConversionType getType();  // AST_TREE | LLM_BASED
    String convert(String source, ConversionContext ctx);
}
```

### SPI-4：Skill 插件（SkillPlugin）

| 实现 | 代码 | 类型 |
|------|------|------|
| EntityRecognizeSkill | `entity-recognize` | ENTITY |
| StandardRuleGenerateSkill | `standard-rule` | STANDARD_RULE |
| MultiFormGenerateSkill | `multi-form` | MULTI_FORM |

```java
public interface SkillPlugin {
    String getCode();
    SkillType getType();
    SkillOutput run(SkillInput input, SkillContext ctx);
    boolean supportsLocal();   // 本地跑
    boolean supportsRemote();  // 远程跑（调用远程 LLM）
}
```

## 3.6 LLM 适配层

```java
public interface LlmClient {
    LlmResponse chatCompletion(LlmRequest request);
}

public class LlmClientFactory {
    public static LlmClient create(String provider) {
        return switch (provider) {
            case "openai"      -> new OpenAiLlmClient(...);
            case "anthropic"   -> new AnthropicLlmClient(...);
            case "ollama"      -> new OllamaLlmClient(...);   // 本地 LLM（orule-skill 用）

        };

}
```

## 3.7 领域模型（实体关系）

```
Domain（元数据域）
├── Entity（业务对象）
│   └── Field（字段）
├── EnumDef（枚举）

├── Skill（Skill 元信息）

```

## 3.10 推进到第 4 轮的输入
