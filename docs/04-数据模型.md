## 4.0 本轮核心变更（相对第 3 轮）

| 变更 | 原方案 | 更新方案 | 来源 |
|------|--------|----------|------|
| Skill 服务层 | 独立 `orule-skill` Python 服务 | **移除**，Skill 直接利用 Cursor/OpenCode 本地环境 | 用户决策 |
| 前端 Skill 调用 | Skill 服务 HTTP 调用 | **前端 MCP Client 直接调用 LLM** + 本地 UI 嵌入卡片 | 用户决策 |
| Skill 设计重点 | Skill 服务本身 | **UI 嵌入 + 切换开关**（规则输入卡片的转换按钮） | 用户决策 |
| 元数据域命名 | `Domain` / `Entity` / `Field` | `DomainType` / `ObjectType` / `AttributeType` | 用户决策 |
| 枚举/函数表名 | `enum_def` / `function_def` | `enum_type` / `function_type` | 用户决策 |
| 函数库命名 | `Function` | `FunctionLib` | 用户决策 |
| 规则域结构 | `Rule` / `RuleVersion` | `RuleSet` / `Rule` / `RuleArtifact` / `RuleSetArtifact` / `RuleTestCase` | 用户决策 + RFC-0008 |
| 编译产物落库 | 内存缓存 | **`compiledGroovy` 等编译产物落库**（RuleArtifact） | 用户决策 |
| **Type 系统（RFC-0031）** | 独立 `enum_type` 表 + `data_type VARCHAR(32)` | **单一 JSON 树** + 5 个 Variant（primitive / enum / object / list / map） | RFC-0031 |
| **`enum_type` 表** | 独立表 + 独立 CRUD | **删除**（enum 定义内联到 `attribute_type.type_json`） | RFC-0031 |
| **`attribute_type.data_type`** | `'string' | 'number' | ... | 'enumRef'` | kind 标签：`primitive / enum / object / list / map` | RFC-0031 |
| **`attribute_type.type_json`** | 不存在 | 新增 JSON 列，存储完整 Type 树 | RFC-0031 |
| **`function_lib.signature`** | VARCHAR(500) 字符串 | JSON（FunctionSignature：params + return） | RFC-0031 |
| `owner_code` 校验 | 未明确 | **强制校验** ObjectType 存在 | Q17 |
| `artifact_uri` | 未明确 | 存**相对 URL**；全局根路径拼接 | Q18 |
| `RuleSetArtifact` | 未明确 | **MVP 需要做** | Q19 |
| `code1..code5` | 5 个固定占位 | 保持占位；`DomainType.RuleForm` 配置决定启用哪些字段 | Q16 |

## 4.1 整体 ER 图（概念层）

```
DomainType（元数据类型）
├── ObjectType（业务对象）
│   └── AttributeType（字段类型）
├── EnumType（枚举类型）
├── FunctionLib（函数库）
└── RuleForm（允许的形态配置）

RuleSet（规则集）
├── name / code
├── domainTypeId → DomainType
└── Rule[]
    ├── RuleSet（维护态）
    │   ├── codeNSOrg（原始自然语言，RuleRepr）
    │   ├── codeSemantic（SimpleTS 源码，RuleSemantic）
    │   ├── code1..N（扩展形态占位；由 DomainType.RuleForm 配置决定启用哪些字段）
    │   └── ownerCode → ObjectType（规则归属）
    ├── RuleArtifact[]（发布态）
    │   ├── engineType（groovy / cruleengine）
    │   ├── compiledCode（编译产物，如 Groovy 脚本）
    │   └── version（制品版本）
    └── RuleTestCase[]（测试用例）
        ├── inputJson（输入事实）
        └── expectedOutput（期望输出）

RuleSetArtifact（规则集发布态）
├── ruleSetId → RuleSet
├── ruleArtifactIds[] → RuleArtifact[]
├── artifactType（JAVA_JAR / JS_BUNDLE / RULE_ENGINE_PACKAGE）
└── artifactUri（相对 URL；全局配置根路径拼接为完整路径）
```

## 4.2 元数据域（DomainType / ObjectType / AttributeType / EnumType / FunctionLib）

### 4.2.1 ER 图（RFC-0031 重构版）

```
DomainType
├── id (PK)
├── code (UK)
├── name
├── description
└── ObjectType[]
    ├── id (PK)
    ├── domainTypeId (FK → DomainType)
    ├── code
    ├── name
    └── AttributeType[]
        ├── id (PK)
        ├── objectTypeId (FK → ObjectType)
        ├── code
        ├── name
        ├── dataType（primitive / enum / object / list / map — kind 标签）
        ├── typeJson（JSON 树：完整 Type 结构）
        ├── nullable（默认 true）
        └── writable（默认 true；false 表示只读字段）

FunctionLib（与 DomainType 平行）
├── id (PK)
├── code (UK)
├── name
├── signature（JSON：FunctionSignature = params[] + returnType）
├── description
└── category

（注：`enum_type` 与 `enum_value` 表已删除，enum 定义内联到 `AttributeType.typeJson` 中）
```

### 4.2.2 表结构

```sql
-- DomainType（元数据类型）
CREATE TABLE domain_type (
    id            VARCHAR(36) PRIMARY KEY,
    code          VARCHAR(100) NOT NULL UNIQUE,
    name          VARCHAR(255) NOT NULL,
    description   TEXT,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- ObjectType（业务对象类型）
CREATE TABLE object_type (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    code          VARCHAR(100) NOT NULL,
    name          VARCHAR(255) NOT NULL,
    description   TEXT,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_object_type_code_per_domain UNIQUE (domain_type_id, code),
    CONSTRAINT fk_object_type_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- AttributeType（字段类型）— RFC-0031 重构
CREATE TABLE attribute_type (
    id              VARCHAR(36) PRIMARY KEY,
    object_type_id   VARCHAR(36) NOT NULL,
    code            VARCHAR(100) NOT NULL,
    name            VARCHAR(255) NOT NULL,
    data_type       VARCHAR(32) NOT NULL,          -- kind 标签: primitive | enum | object | list | map
    type_json       JSON NOT NULL,                  -- 完整 Type 结构（Jackson 多态序列化）
    nullable        BOOLEAN DEFAULT TRUE,
    writable        BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_attribute_type_code_per_object UNIQUE (object_type_id, code),
    CONSTRAINT fk_attribute_type_object_type FOREIGN KEY (object_type_id) REFERENCES object_type(id)
);

CREATE INDEX idx_attribute_type_data_type ON attribute_type(data_type);

-- enum_type / enum_value 表已删除（RFC-0031）：enum 定义内联到 attribute_type.type_json.values

-- FunctionLib（函数库）— RFC-0031 重构：signature 改为 JSON
CREATE TABLE function_lib (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    code          VARCHAR(100) NOT NULL,
    name          VARCHAR(255) NOT NULL,
    signature     JSON NOT NULL,                    -- FunctionSignature = { params: Type[], return: Type }
    impl_ref      VARCHAR(255),                     -- 实现引用（Groovy 类方法或外部服务 URL）
    description   TEXT,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_function_lib_code_per_domain UNIQUE (domain_type_id, code),
    CONSTRAINT fk_function_lib_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- RuleForm（允许的形态配置）
CREATE TABLE rule_form (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    form_code     VARCHAR(50) NOT NULL,           -- 'nl' | 'table' | 'simplets' | 'ts-json' | 'code_1' .. 'code_5'
    enabled       BOOLEAN DEFAULT TRUE,
    priority      INT DEFAULT 0,
    CONSTRAINT uk_rule_form_per_domain UNIQUE (domain_type_id, form_code),
    CONSTRAINT fk_rule_form_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);
```

## 4.3 规则域（RuleSet / Rule / RuleArtifact / RuleSetArtifact）

### 4.3.1 设计原则

继承 RFC-0008 的三层结构：

```
RuleRepr[]（表现层）   ← codeNSOrg（原始自然语言）
RuleSemantic（语义层） ← codeSemantic（SimpleTS 源码）
RuleExecution[]（执行层）← RuleArtifact（编译产物）
```

- **维护态**：业务人员/工程师看到的版本（codeNSOrg + codeSemantic + code1..code5）
- **发布态**：引擎实际执行的版本（RuleArtifact，编译产物落库）
- **规则集发布态**：多条规则打包后的产物（RuleSetArtifact）

### 4.3.2 ER 图

```
RuleSet（规则集）
├── id (PK)
├── code (UK)
├── name
├── domainTypeId → DomainType
├── ownerCode → ObjectType.code（规则归属）
├── status（DRAFT / PUBLISHED）
└── Rule[]
    ├── id (PK)
    ├── ruleSetId (FK → RuleSet)
    ├── code
    ├── name
    ├── ownerCode → ObjectType.code（**强制校验存在**）
    ├── ruleType（ATOMIC / COMPOSITE）
    ├── compositeType（当 ruleType=COMPOSITE 时）
    └── RuleVersion[]
        ├── id (PK)
        ├── ruleId (FK → Rule)
        ├── version (INT，自增)
        ├── codeNSOrg（原始自然语言，RuleRepr）
        ├── codeSemantic（SimpleTS 源码，RuleSemantic）
        ├── code1..code5（扩展形态占位）
        ├── tsAst（运行期 IR JSON）
        ├── llmGenerated（是否 LLM 生成）
        ├── validationStatus（VALID / INVALID / PENDING）
        ├── validationErrors（JSON）
        └── createdAt

    ├── RuleArtifact[]（发布态）
    │   ├── id (PK)
    │   ├── ruleId (FK → Rule)
    │   ├── ruleVersionId (FK → RuleVersion)
    │   ├── engineType（groovy / cruleengine / js）
    │   ├── compiledCode（编译产物，如 Groovy 脚本）
    │   ├── artifactVersion
    │   └── status（ACTIVE / DEPRECATED）

    └── RuleTestCase[]（测试用例）
        ├── id (PK)
        ├── ruleId (FK → Rule)
        ├── inputJson（输入事实）
        └── expectedOutput（期望输出）

RuleSetArtifact（规则集发布态）
├── id (PK)
├── ruleSetId → RuleSet
├── ruleArtifactIds[]（JSON，制品 ID 列表）
├── artifactType（JAVA_JAR / JS_BUNDLE / RULE_ENGINE_PACKAGE）
├── artifactUri（相对 URL；全局根路径拼接）
└── artifactVersion
```

### 4.3.3 表结构

```sql
-- RuleSet（规则集）
CREATE TABLE rule_set (
    id               VARCHAR(36) PRIMARY KEY,
    code             VARCHAR(100) NOT NULL UNIQUE,
    name             VARCHAR(255) NOT NULL,
    description      TEXT,
    domain_type_id   VARCHAR(36) NOT NULL,
    owner_code       VARCHAR(100) NOT NULL,
    status           VARCHAR(20) DEFAULT 'DRAFT',
    current_version_id VARCHAR(36),
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at       TIMESTAMP,
    CONSTRAINT fk_rule_set_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- Rule（规则）
CREATE TABLE rule (
    id               VARCHAR(36) PRIMARY KEY,
    rule_set_id      VARCHAR(36) NOT NULL,
    code             VARCHAR(100) NOT NULL,
    name             VARCHAR(255) NOT NULL,
    description      TEXT,
    owner_code       VARCHAR(100) NOT NULL,              -- 引用的 ObjectType.code，强制校验存在
    current_version_id VARCHAR(36),
    rule_type        VARCHAR(20) DEFAULT 'ATOMIC',       -- ATOMIC / COMPOSITE
    composite_type   VARCHAR(20),
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at       TIMESTAMP,
    CONSTRAINT uk_rule_code_per_set UNIQUE (rule_set_id, code),
    CONSTRAINT fk_rule_set FOREIGN KEY (rule_set_id) REFERENCES rule_set(id)
);

-- RuleVersion（规则版本 = 维护态）
CREATE TABLE rule_version (
    id                  VARCHAR(36) PRIMARY KEY,
    rule_id             VARCHAR(36) NOT NULL,
    version             INT NOT NULL,
    -- 表现层（RuleRepr[]）
    code_ns_org         TEXT,
    -- 语义层（RuleSemantic）
    code_semantic       TEXT,
    -- 扩展形态占位（由 DomainType.RuleForm 配置决定启用哪些字段）
    code_1              TEXT,
    code_2              TEXT,
    code_3              TEXT,
    code_4              TEXT,
    code_5              TEXT,
    -- 运行期 IR
    ts_ast              JSON,
    -- 元数据
    llm_generated       BOOLEAN DEFAULT FALSE,
    validation_status   VARCHAR(20) DEFAULT 'PENDING',
    validation_errors   JSON,
    created_by          VARCHAR(100),
    created_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT uk_rule_version UNIQUE (rule_id, version),
    CONSTRAINT fk_rule_version_rule FOREIGN KEY (rule_id) REFERENCES rule(id)
);

-- RuleArtifact（规则发布态 = 执行层）
CREATE TABLE rule_artifact (
    id               VARCHAR(36) PRIMARY KEY,
    rule_id          VARCHAR(36) NOT NULL,
    rule_version_id  VARCHAR(36) NOT NULL,
    engine_type      VARCHAR(50) NOT NULL,
    compiled_code    TEXT NOT NULL,
    artifact_version INT NOT NULL DEFAULT 1,
    status           VARCHAR(20) DEFAULT 'ACTIVE',
    description      TEXT,
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_artifact_rule FOREIGN KEY (rule_id) REFERENCES rule(id),
    CONSTRAINT fk_artifact_version FOREIGN KEY (rule_version_id) REFERENCES rule_version(id)
);

-- RuleSetArtifact（规则集发布态）
CREATE TABLE rule_set_artifact (
    id              VARCHAR(36) PRIMARY KEY,
    rule_set_id     VARCHAR(36) NOT NULL,
    rule_ids_json   JSON NOT NULL,
    artifact_type   VARCHAR(50) NOT NULL,               -- 'JAR' | 'JS_BUNDLE' | 'RULE_ENGINE_PACKAGE'
    artifact_uri    VARCHAR(500) NOT NULL,               -- 相对 URL（如 "artifacts/order-discount/1.0.0.jar"）；由 ArtifactStorage 接口解析（ADR-010）
    artifact_version INT NOT NULL DEFAULT 1,
    status          VARCHAR(20) DEFAULT 'ACTIVE',
    concurrency     INT DEFAULT 1,                      -- 批量执行并发度；默认 1（顺序）；-1 表示全并行；由 BatchExecutionService 消费（ADR-010）
    storage_type    VARCHAR(20) DEFAULT 'local',        -- 制品存储后端类型：local / s3 / oss / minio（ADR-010）
    storage_key     VARCHAR(500),                       -- 存储后端的实际 key（与 artifact_uri 区别：uri 是逻辑路径，key 是物理路径）
    checksum        VARCHAR(64),                        -- SHA-256
    size_bytes      BIGINT,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_set_artifact_set FOREIGN KEY (rule_set_id) REFERENCES rule_set(id)
);

-- RuleTestCase（测试用例）
CREATE TABLE rule_test_case (
    id              VARCHAR(36) PRIMARY KEY,
    rule_id         VARCHAR(36) NOT NULL,
    name            VARCHAR(255) NOT NULL,
    description     TEXT,
    input_json      JSON NOT NULL,
    expected_output JSON,
    last_result     JSON,
    last_passed     BOOLEAN,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_test_case_rule FOREIGN KEY (rule_id) REFERENCES rule(id)
);
```

## 4.5 多版本策略与软删除

### 4.5.1 多版本策略

- **每保存一次生成新版本**：`rule_version.version` 自增
- `rule.current_version_id` 指向当前生效版本
- 历史版本**永久保留**，不做自动清理
- MVP 无版本数上限

### 4.5.2 软删除

| 表 | 删除策略 |
|----|----------|
| `rule_set` | 软删除（`deleted_at`） |
| `rule` | 软删除（`deleted_at`） |
| `rule_version` | 不允许删除（immutable） |
| `rule_artifact` | 标记 `status=DEPRECATED` |
| `execution` | 不允许删除（审计事实） |

## 4.8 DomainType 持久化映射（拼装 DomainMeta）

`DomainMeta`（SimpleTS 编译所需的元数据）由以下表拼装：

```java
public class DomainMeta {
    String id;                                    // → domain_type.code
    List<EnumType> enums;                         // → enum_type
    List<ObjectTypeDef> entities;                  // → object_type + attribute_type
    List<ContextVar> context;                     // 由 domain_type 配置的入口变量
}

// 拼装逻辑（在 RuleService 中实现）
DomainMeta buildMeta(String domainTypeId) {
    DomainType dt = domainTypeRepo.findById(domainTypeId);
    List<ObjectType> objects = objectTypeRepo.findByDomainTypeId(domainTypeId);
    return DomainMeta.builder()
        .id(dt.getCode())
        .enums(enumTypeRepo.findByDomainTypeId(domainTypeId).stream().map(...))
        .entities(objects.stream().map(obj ->
            ObjectTypeDef.builder()
                .id(obj.getCode())
                .fields(attributeTypeRepo.findByObjectTypeId(obj.getId()).stream().map(...))
                .build()
        ).toList())
        .context(buildContextVars(domainTypeId))
        .build();
}
```

## 4.9 Skill UI 嵌入设计（前端）

### 4.9.1 设计背景

MVP 阶段不使用独立 Skill 服务。Skill 能力通过 **前端 MCP Client** 直接调用 LLM 实现。

### 4.9.2 UI 嵌入卡片设计

规则编辑器中嵌入 Skill 调用卡片：

```
┌──────────────────────────────────────────────────────────────┐
│  规则编辑器                                                    │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │  [SimpleTS 源码]  │  [自然语言]  │  [表格]  │ [JSON]  │  ← 切换开关
│  └─────────────────────────────────────────────────────────┘ │
│                                                              │
│  ┌──────────────────────┐  ┌─────────────────────────────┐ │
│  │  SimpleTS 源码编辑器   │  │  🔄 Skill 调用卡片           │ │
│  │  textarea            │  │                             │ │
│  │                       │  │  输入：NL 描述              │ │
│  │  if (customer.tier   │  │  → [生成 SimpleTS] 按钮     │ │
│  │   == CustomerTier.VIP │  │                             │ │
│  │   && order.amount     │  │  或                         │ │
│  │   >= 200) {           │  │  输入：SimpleTS             │ │
│  │    order.discount=30  │  │  → [生成自然语言] 按钮      │ │
│  │  }                    │  │                             │ │
│  └──────────────────────┘  └─────────────────────────────┘ │
│                                                              │
│  [保存]  [执行测试]  [查看制品]                                │
└──────────────────────────────────────────────────────────────┘
```

**关键设计点**：
- **切换开关**：四视图（SimpleTS / 自然语言 / 表格 / JSON）通过 Tab 切换，**内容同步**
- **Skill 调用卡片**：嵌在编辑器右侧，可折叠/展开
- **转换按钮**：触发 LLM 调用（`NlToSimpletsConverter` / `SimpletsToNlConverter`）
- 本地 UI 嵌入通过 **前端 MCP Client** 与 `orule-server` 通信

### 4.9.3 切换开关同步逻辑

```
用户切换视图
     │
     ▼
读取当前 rule_version（code_semantic）
     │
     ├── 切到 SimpleTS 视图 → 直接显示 code_semantic
     ├── 切到 NL 视图       → 调用 NlToSimpletsConverter（LLM_BASED，SimpleTS → NL）
     ├── 切到表格视图       → 调用 SimpletsToTableConverter（AST_TREE，SimpleTS → Table）
     └── 切到 JSON 视图     → 只读显示 ts_ast（TS-AST JSON，调试用，不作为主编辑视图）

> **架构约束（ADR-009）**：所有切换都**以 SimpleTS 为中心**，不存在 NL ↔ Table 直接切换。
```

## 4.10 推进到第 5 轮的输入

| 输入项 | 值 |
|--------|-----|
| 元数据域 | `DomainType` / `ObjectType` / `AttributeType` / `EnumType` / `FunctionLib` / `RuleForm` |
| 规则域 | `RuleSet` / `Rule` / `RuleVersion` / `RuleArtifact` / `RuleSetArtifact` / `RuleTestCase` |
| 执行域 | `Execution` / `ExecutionLog`（append-only，不删除） |
| 编译产物 | **落库**（`rule_artifact.compiled_code`） |
| 多版本 | 每保存一次升 version，历史永久保留 |
| 软删除 | `rule_set` / `rule` 软删；`rule_version` / `execution` 不允许删除 |
| Skill 层 | 无独立服务；前端 MCP Client + LLM；Skill UI 卡片嵌入编辑器 |
| 视图同步 | **以 SimpleTS 为中心**的星型结构（NL ↔ SimpleTS / Table ↔ SimpleTS / TS-AST & Groovy 只读） |
| Flyway | 5 个 migration（V1-V5），三 DB 共用 |
| `owner_code` 校验 | **强制校验** ObjectType 存在 |
| `artifact_uri` | 存**相对 URL**；由 `ArtifactStorage` 接口解析（默认本地文件系统，可替换 S3/OSS/MinIO，ADR-010） |
| `code1..code5` | 保持占位；`DomainType.RuleForm` 配置决定启用哪些字段 |
| `RuleSetArtifact` | **MVP 需要做** |
| `concurrency` | 批量执行并发度，默认 1（顺序）；-1 全并行（ADR-010） |
| `storage_type` / `storage_key` | 制品存储后端类型 + 物理 key（ADR-010） |
