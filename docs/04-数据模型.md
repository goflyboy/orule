## 4.0 本轮核心变更（相对第 3 轮）

| 变更 | 原方案 | 更新方案 | 来源 |
|------|--------|----------|------|

| 编译产物落库 | 内存缓存 | **`compiledGroovy` 等编译产物落库**（RuleArtifact） | 用户决策 |

## 4.1 整体 ER 图（概念层）

```
DomainType（元数据域）
├── ObjectType（业务对象）
│   └── Attribute（字段）
├── EnumDef（枚举）
├── Function（函数库）
└── RuleForm（允许的形态配置）

RuleSet（规则集）
├── name / code
├── domainTypeId → DomainType
└── Rule[]
    ├── RuleSet（维护态）
    │   ├── codeNSOrg（原始自然语言，RuleRepr）
    │   ├── codeSemantic（SimpleTS 源码，RuleSemantic）
    │   ├── code1..N（扩展形态占位）
    │   └── ownerCode → ObjectType（规则归属）
    ├── RuleArtifact[]（发布态）
    │   ├── engineType（groovy / cruleengine）
    │   ├── compiledCode（编译产物，如 Groovy 脚本）
    │   └── version（制品版本）
    └── RuleTestCase[]（测试用例）
        ├── inputJson（输入事实）
        └── expectedOutput（期望输出）

RuleSetArtifact（规则集发布态）
├── ruleSetId → RuleSet
├── ruleArtifactIds[] → RuleArtifact[]
├── artifactType（JAVA_JAR / JS_BUNDLE / RULE_ENGINE_PACKAGE）
└── artifactUri（打包产物路径/内容）
```

## 4.2 元数据域（DomainType / ObjectType / Attribute）

### 4.2.1 ER 图

```
DomainType
├── id (PK)
├── code (UK)
├── name
├── description
└── ObjectType[]
    ├── id (PK)
    ├── domainTypeId (FK → DomainType)
    ├── code
    ├── name
    └── Attribute[]
        ├── id (PK)
        ├── objectTypeId (FK → ObjectType)
        ├── code
        ├── name
        ├── dataType（string / number / boolean / date / enumRef）
        ├── enumDefId?（FK → EnumDef，当 dataType=enumRef 时）
        ├── nullable（默认 true）
        └── writable（默认 true；false 表示只读字段）
```

### 4.2.2 表结构

```sql
-- DomainType（元数据类型）
CREATE TABLE domain_type (
    id            VARCHAR(36) PRIMARY KEY,
    code          VARCHAR(100) NOT NULL UNIQUE,
    name          VARCHAR(255) NOT NULL,
    description   TEXT,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- ObjectType（业务对象类型）
CREATE TABLE object_type (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    code          VARCHAR(100) NOT NULL,
    name          VARCHAR(255) NOT NULL,
    description   TEXT,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_object_type_code_per_domain UNIQUE (domain_type_id, code),
    CONSTRAINT fk_object_type_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- Attribute（字段）
CREATE TABLE attribute (
    id              VARCHAR(36) PRIMARY KEY,
    object_type_id   VARCHAR(36) NOT NULL,
    code            VARCHAR(100) NOT NULL,
    name            VARCHAR(255) NOT NULL,
    data_type       VARCHAR(50) NOT NULL,          -- 'string' | 'number' | 'boolean' | 'date' | 'enumRef'
    enum_def_id     VARCHAR(36),                   -- 当 data_type='enumRef' 时引用
    nullable        BOOLEAN DEFAULT TRUE,
    writable        BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_attr_code_per_object UNIQUE (object_type_id, code),
    CONSTRAINT fk_attr_object_type FOREIGN KEY (object_type_id) REFERENCES object_type(id),
    CONSTRAINT fk_attr_enum_def FOREIGN KEY (enum_def_id) REFERENCES enum_def(id)
);

-- EnumDef（枚举定义）
CREATE TABLE enum_def (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    code          VARCHAR(100) NOT NULL,
    name          VARCHAR(255) NOT NULL,
    values_json   JSON NOT NULL,                  -- ["VIP", "NORMAL"]
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_enum_code_per_domain UNIQUE (domain_type_id, code),
    CONSTRAINT fk_enum_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- Function（函数库）
CREATE TABLE function_def (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    code          VARCHAR(100) NOT NULL,
    name          VARCHAR(255) NOT NULL,
    signature     VARCHAR(500) NOT NULL,          -- "min(a: number, b: number): number"
    impl_ref      VARCHAR(255),                    -- 实现引用（Groovy 类方法或外部服务 URL）
    description   TEXT,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT uk_func_code_per_domain UNIQUE (domain_type_id, code),
    CONSTRAINT fk_func_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- RuleForm（允许的形态配置）
CREATE TABLE rule_form (
    id            VARCHAR(36) PRIMARY KEY,
    domain_type_id VARCHAR(36) NOT NULL,
    form_code     VARCHAR(50) NOT NULL,           -- 'nl' | 'table' | 'simplets' | 'ts-json'
    enabled       BOOLEAN DEFAULT TRUE,
    priority      INT DEFAULT 0,
    CONSTRAINT uk_rule_form_per_domain UNIQUE (domain_type_id, form_code),
    CONSTRAINT fk_rule_form_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);
```

## 4.3 规则域（RuleSet / Rule / RuleArtifact / RuleSetArtifact）

### 4.3.1 设计原则

继承 RFC-0008 的三层结构：

```
RuleRepr[]（表现层）   ← codeNSOrg（原始自然语言）
RuleSemantic（语义层） ← codeSemantic（SimpleTS 源码）
RuleExecution[]（执行层）← RuleArtifact（编译产物）
```

- **维护态**：业务人员/工程师看到的版本（codeNSOrg + codeSemantic + code1..N）
- **发布态**：引擎实际执行的版本（RuleArtifact，编译产物落库）
- **规则集发布态**：多条规则打包后的产物（RuleSetArtifact）

### 4.3.2 ER 图

```
RuleSet（规则集）
├── id (PK)
├── code (UK)
├── name
├── description
├── domain_type_id → DomainType
├── owner_code → ObjectType.code（规则归属的业务对象）
├── status（DRAFT / PUBLISHED）
├── current_version_id → RuleVersion（当前生效版本）
└── Rule[]
    ├── id (PK)
    ├── rule_set_id (FK → RuleSet)
    ├── code
    ├── name
    ├── owner_code → ObjectType.code（引用 DomainType.ObjectType.code）
    ├── current_version_id → RuleVersion
    ├── rule_type（ATOMIC / COMPOSITE）
    ├── composite_type（ALL / ANY / WHITE_LIST / BLACK_LIST / SEQUENCE；当 rule_type=COMPOSITE 时）
    └── RuleVersion[]
        ├── id (PK)
        ├── rule_id (FK → Rule)
        ├── version (INT，自增)
        ├── code_ns_org（原始自然语言，RuleRepr）
        ├── code_semantic（SimpleTS 源码，RuleSemantic）
        ├── code1..code5（扩展形态占位）
        ├── ts_ast（运行期 IR JSON）
        ├── llm_generated（是否 LLM 生成）
        ├── validation_status（VALID / INVALID / PENDING）
        ├── validation_errors（JSON，校验失败时）
        ├── created_by（用户 ID 或 Agent ID）
        └── created_at

    ├── RuleArtifact[]（发布态）
    │   ├── id (PK)
    │   ├── rule_id (FK → Rule)
    │   ├── rule_version_id (FK → RuleVersion)
    │   ├── engine_type（groovy / cruleengine / js）
    │   ├── compiled_code（编译产物，如 Groovy 脚本）
    │   ├── artifact_version（制品版本号）
    │   ├── status（ACTIVE / DEPRECATED）
    │   └── created_at

    └── RuleTestCase[]（测试用例）
        ├── id (PK)
        ├── rule_id (FK → Rule)
        ├── name
        ├── input_json（JSON，输入事实）
        ├── expected_output（JSON，期望输出）
        └── last_result（JSON，最近一次执行结果）
```

### 4.3.3 表结构

```sql
-- RuleSet（规则集）
CREATE TABLE rule_set (
    id               VARCHAR(36) PRIMARY KEY,
    code             VARCHAR(100) NOT NULL UNIQUE,
    name             VARCHAR(255) NOT NULL,
    description      TEXT,
    domain_type_id   VARCHAR(36) NOT NULL,
    owner_code       VARCHAR(100) NOT NULL,              -- 归属的 ObjectType.code
    status           VARCHAR(20) DEFAULT 'DRAFT',       -- DRAFT / PUBLISHED
    current_version_id VARCHAR(36),
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at       TIMESTAMP,                          -- 软删除
    CONSTRAINT fk_rule_set_domain FOREIGN KEY (domain_type_id) REFERENCES domain_type(id)
);

-- Rule（规则）
CREATE TABLE rule (
    id               VARCHAR(36) PRIMARY KEY,
    rule_set_id      VARCHAR(36) NOT NULL,
    code             VARCHAR(100) NOT NULL,
    name             VARCHAR(255) NOT NULL,
    description      TEXT,
    owner_code       VARCHAR(100) NOT NULL,              -- 引用的 ObjectType.code
    current_version_id VARCHAR(36),
    rule_type        VARCHAR(20) DEFAULT 'ATOMIC',       -- ATOMIC / COMPOSITE
    composite_type   VARCHAR(20),                        -- 当 rule_type=COMPOSITE 时
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at       TIMESTAMP,
    CONSTRAINT uk_rule_code_per_set UNIQUE (rule_set_id, code),
    CONSTRAINT fk_rule_set FOREIGN KEY (rule_set_id) REFERENCES rule_set(id)
);

-- RuleVersion（规则版本 = 维护态）
-- 对应 RFC-0008 的 RuleRepr[] + RuleSemantic
CREATE TABLE rule_version (
    id                  VARCHAR(36) PRIMARY KEY,
    rule_id             VARCHAR(36) NOT NULL,
    version             INT NOT NULL,
    -- 表现层（RuleRepr[]）
    code_ns_org         TEXT,                            -- 原始自然语言
    -- 语义层（RuleSemantic）
    code_semantic       TEXT,                            -- SimpleTS 源码
    -- 扩展形态占位（RuleRepr 扩展）
    code_1              TEXT,                            -- 扩展形态 1
    code_2              TEXT,                            -- 扩展形态 2
    code_3              TEXT,                            -- 扩展形态 3
    -- 运行期 IR
    ts_ast              JSON,                            -- TS-AST JSON
    -- 元数据
    llm_generated       BOOLEAN DEFAULT FALSE,
    validation_status   VARCHAR(20) DEFAULT 'PENDING',  -- VALID / INVALID / PENDING
    validation_errors   JSON,                            -- 校验失败时收集的错误
    created_by          VARCHAR(100),                    -- 用户 ID 或 Agent ID
    created_at          TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT uk_rule_version UNIQUE (rule_id, version),
    CONSTRAINT fk_rule_version_rule FOREIGN KEY (rule_id) REFERENCES rule(id)
);

-- RuleArtifact（规则发布态 = 执行层）
-- 对应 RFC-0008 的 RuleExecution[]
CREATE TABLE rule_artifact (
    id               VARCHAR(36) PRIMARY KEY,
    rule_id          VARCHAR(36) NOT NULL,
    rule_version_id  VARCHAR(36) NOT NULL,
    engine_type      VARCHAR(50) NOT NULL,              -- 'groovy' | 'cruleengine' | 'js'
    compiled_code    TEXT NOT NULL,                     -- 编译产物（如 Groovy 脚本）
    artifact_version INT NOT NULL DEFAULT 1,
    status           VARCHAR(20) DEFAULT 'ACTIVE',       -- ACTIVE / DEPRECATED
    description      TEXT,
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_artifact_rule FOREIGN KEY (rule_id) REFERENCES rule(id),
    CONSTRAINT fk_artifact_version FOREIGN KEY (rule_version_id) REFERENCES rule_version(id)
);

-- RuleSetArtifact（规则集发布态）
-- 对应 RFC-0008 的 RulesSetArtifact
CREATE TABLE rule_set_artifact (
    id              VARCHAR(36) PRIMARY KEY,
    rule_set_id     VARCHAR(36) NOT NULL,
    rule_ids_json   JSON NOT NULL,                      -- [rule_id1, rule_id2, ...]
    artifact_type   VARCHAR(50) NOT NULL,               -- 'JAR' | 'JS_BUNDLE' | 'RULE_ENGINE_PACKAGE'
    artifact_uri    VARCHAR(500),                       -- 打包产物路径或内容
    artifact_version INT NOT NULL DEFAULT 1,
    status          VARCHAR(20) DEFAULT 'ACTIVE',
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_set_artifact_set FOREIGN KEY (rule_set_id) REFERENCES rule_set(id)
);

-- RuleTestCase（测试用例）
CREATE TABLE rule_test_case (
    id              VARCHAR(36) PRIMARY KEY,
    rule_id         VARCHAR(36) NOT NULL,
    name            VARCHAR(255) NOT NULL,
    description     TEXT,
    input_json      JSON NOT NULL,                      -- 输入事实
    expected_output JSON,                               -- 期望输出
    last_result     JSON,                               -- 最近一次执行结果
    last_passed     BOOLEAN,                           -- 最近一次是否通过
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_test_case_rule FOREIGN KEY (rule_id) REFERENCES rule(id)
);
```

## 4.4 执行域（Execution / ExecutionLog）

### 4.4.1 设计原则

- 执行记录永久保留（append-only），不做软删除
- 执行日志按 `trace_id` 关联，可追溯每个节点的决策路径
- 编译产物（`compiled_code`）已落 `rule_artifact` 表，执行时直接读取，不重复编译

### 4.4.2 表结构

```sql
-- Execution（执行记录）
CREATE TABLE execution (
    id               VARCHAR(36) PRIMARY KEY,
    rule_id          VARCHAR(36) NOT NULL,
    rule_version_id  VARCHAR(36) NOT NULL,
    rule_artifact_id VARCHAR(36),                       -- 使用的制品版本
    engine_type      VARCHAR(50) NOT NULL,
    input_json       JSON NOT NULL,                      -- 输入事实
    output_json      JSON,                              -- 输出结果
    status           VARCHAR(20) NOT NULL,              -- SUCCESS / FAILURE / ERROR
    error_message    TEXT,
    trace_id         VARCHAR(100) NOT NULL,              -- 追溯 ID（关联 ExecutionLog）
    elapsed_ms       BIGINT,                             -- 执行耗时（毫秒）
    executed_by      VARCHAR(100),                        -- 用户 ID 或 Agent ID
    created_at       TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_execution_rule FOREIGN KEY (rule_id) REFERENCES rule(id),
    CONSTRAINT fk_execution_version FOREIGN KEY (rule_version_id) REFERENCES rule_version(id),
    CONSTRAINT fk_execution_artifact FOREIGN KEY (rule_artifact_id) REFERENCES rule_artifact(id)
);

-- ExecutionLog（执行日志，行号级追溯）
-- 每个 AST 节点对应一行日志，可重建完整决策路径
CREATE TABLE execution_log (
    id              VARCHAR(36) PRIMARY KEY,
    execution_id    VARCHAR(36) NOT NULL,
    trace_id        VARCHAR(100) NOT NULL,
    node_id         VARCHAR(100),                       -- AST 节点 ID（如 "if.cond", "assign.1"）
    source_line     INT,                                 -- 对应 SimpleTS 源码行号
    level           VARCHAR(10) NOT NULL,               -- TRACE / DEBUG / INFO / WARN / ERROR
    message         TEXT NOT NULL,
    details_json    JSON,                               -- 节点输入/输出/条件值
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_log_execution FOREIGN KEY (execution_id) REFERENCES execution(id),
    CONSTRAINT idx_execution_trace_id (trace_id),
    CONSTRAINT idx_execution_created_at (created_at)
);
```

## 4.5 多版本策略与软删除

### 4.5.1 多版本策略

- **每保存一次生成新版本**：`rule_version.version` 自增
- `rule.current_version_id` 指向当前生效版本（可通过 MCP 工具 `rule_get?version=latest` 读取）
- 历史版本**永久保留**，不做自动清理
- 最多保留版本数：MVP 无上限，二期可加 `max_versions` 配置

### 4.5.2 软删除

| 表 | 删除策略 | 说明 |
|----|----------|------|
| `rule_set` | 软删除（`deleted_at`） | 保留执行历史关联 |
| `rule` | 软删除（`deleted_at`） | 保留执行历史关联 |
| `rule_version` | 不允许删除 | 版本是 immutable 事实 |
| `rule_artifact` | 标记 `status=DEPRECATED` | 保留历史制品 |
| `execution` | 不允许删除 | 执行记录是审计事实 |

## 4.8 DomainMeta 持久化映射

`DomainMeta`（SimpleTS 编译所需的元数据）由以下表拼装：

```java
public class DomainMeta {
    String id;                                    // → domain_type.code
    List<EnumDef> enums;                          // → enum_def
    List<EntityDef> entities;                      // → object_type + attribute
    List<ContextVar> context;                     // 由 domain_type 配置的入口变量
}

// 拼装逻辑（在 RuleService 中实现）
DomainMeta buildMeta(String domainTypeId) {
    DomainType dt = domainTypeRepo.findById(domainTypeId);
    List<ObjectType> objects = objectTypeRepo.findByDomainTypeId(domainTypeId);
    return DomainMeta.builder()
        .id(dt.getCode())
        .enums(enumDefRepo.findByDomainTypeId(domainTypeId).stream().map(...))
        .entities(objects.stream().map(obj ->
            EntityDef.builder()
                .id(obj.getCode())
                .fields(attributeRepo.findByObjectTypeId(obj.getId()).stream().map(...))
                .build()
        ).toList())
        .context(buildContextVars(domainTypeId))  // 从 domain_type 配置读取
        .build();
}
```

## 4.9 Skill UI 嵌入设计（前端）

### 4.9.1 设计背景

MVP 阶段不使用独立 Skill 服务。Skill 能力通过 **前端 MCP Client** 直接调用 LLM 实现。

### 4.9.2 UI 嵌入卡片设计

规则编辑器中嵌入 Skill 调用卡片：

```
┌──────────────────────────────────────────────────────────────┐
│  规则编辑器                                                    │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │  [SimpleTS 源码]  │  [自然语言]  │  [表格]  │ [JSON]  │  ← 切换开关
│  └─────────────────────────────────────────────────────────┘ │
│                                                              │
│  ┌──────────────────────┐  ┌─────────────────────────────┐ │
│  │  SimpleTS 源码编辑器   │  │  🔄 Skill 调用卡片           │ │
│  │  textarea            │  │                             │ │
│  │                       │  │  输入：NL 描述              │ │
│  │  if (customer.tier   │  │  → [生成 SimpleTS] 按钮     │ │
│  │   == CustomerTier.VIP │  │                             │ │
│  │   && order.amount     │  │  或                         │ │
│  │   >= 200) {           │  │  输入：SimpleTS             │ │
│  │    order.discount=30  │  │  → [生成自然语言] 按钮      │ │
│  │  }                    │  │                             │ │
│  └──────────────────────┘  └─────────────────────────────┘ │
│                                                              │
│  [保存]  [执行测试]  [查看制品]                                │
└──────────────────────────────────────────────────────────────┘
```

**关键设计点**：
- **切换开关**：四视图（SimpleTS / 自然语言 / 表格 / JSON）通过 Tab 切换，**内容同步**
- **Skill 调用卡片**：嵌在编辑器右侧，可折叠/展开
- **转换按钮**：触发 LLM 调用（`NlToSimpletsConverter` / `SimpletsToNlConverter`）
- 本地 UI 嵌入通过 **前端 MCP Client** 与 `orule-server` 通信

### 4.9.3 切换开关同步逻辑

```
用户切换视图
     │
     ▼
读取当前 rule_version（code_semantic）
     │
     ├── 切到 SimpleTS 视图 → 直接显示 code_semantic
     ├── 切到 NL 视图       → 调用 NlToSimpletsConverter（LLM_BASED）
     ├── 切到表格视图       → 调用 SimpletsToTableConverter（AST_TREE）
     └── 切到 JSON 视图     → 显示 ts_ast（TS-AST JSON）
```

## 4.10 推进到第 5 轮的输入

| 输入项 | 值 |
|--------|-----|
| 元数据域 | `DomainType` / `ObjectType` / `Attribute` / `EnumDef` / `Function` / `RuleForm` |
| 规则域 | `RuleSet` / `Rule` / `RuleVersion` / `RuleArtifact` / `RuleSetArtifact` / `RuleTestCase` |
| 执行域 | `Execution` / `ExecutionLog`（append-only，不删除） |
| 编译产物 | **落库**（`rule_artifact.compiled_code`） |
| 多版本 | 每保存一次升 version，历史永久保留 |
| 软删除 | `rule_set` / `rule` 软删；`rule_version` / `execution` 不允许删除 |
| Skill 层 | 无独立服务；前端 MCP Client + LLM；Skill UI 卡片嵌入编辑器 |
| 切换开关 | 四视图（SimpleTS / NL / Table / JSON）内容同步 |
| Flyway | 5 个 migration（V1-V5），三 DB 共用 |
