# RFC-0013: 本地一键启动脚本

> **状态**：DRAFT · **优先级**：P0 · **预计工作量**：1d · **阶段**：S0

---

## 1. 摘要

编写 `scripts/dev-start.sh`（Linux/macOS）和 `scripts/dev-start.ps1`（Windows PowerShell），一键启动 orule-server、orule-runtime、orule-web（占位）等服务。

---

## 2. 动机

- 当前新人启动需要分别启动 server / runtime / web，门槛高
- 依据 `08-开发视图 §8.4.3` 的一键启动脚本定义
- 支撑 MVP 阶段的本地演示

---

## 3. 详细设计

### 3.1 Linux / macOS（`scripts/dev-start.sh`）

```bash
#!/usr/bin/env bash
# scripts/dev-start.sh
# 一键启动 orule 本地一体化开发环境

set -e

# 颜色输出
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

log() { echo -e "${GREEN}[$(date +'%H:%M:%S')]${NC} $1"; }
warn() { echo -e "${YELLOW}[$(date +'%H:%M:%S')]${NC} $1"; }
err() { echo -e "${RED}[$(date +'%H:%M:%S')] ERROR:${NC} $1"; exit 1; }

# 检查依赖
command -v java >/dev/null 2>&1 || err "未找到 java，请安装 JDK 21+"
command -v mvn >/dev/null 2>&1 || err "未找到 mvn，请安装 Maven 3.9+"

JAVA_VER=$(java -version 2>&1 | head -n1 | awk -F '"' '{print $2}' | awk -F '.' '{print $1}')
[ "$JAVA_VER" -ge 21 ] || err "需要 JDK 21+，当前 $JAVA_VER"

log "🚀 启动 orule 本地一体化开发环境..."

# 创建数据目录
mkdir -p ~/orule/data/db ~/orule/data/artifacts ~/orule/data/logs

# 启动 orule-server（后台）
log "🟢 启动 orule-server（端口 8080）..."
(cd packages/orule-server && mvn spring-boot:run) > ~/orule/data/logs/server.log 2>&1 &
SERVER_PID=$!

# 等待 server 健康
log "⏳ 等待 orule-server 就绪..."
for i in {1..30}; do
  if curl -s http://localhost:8080/actuator/health > /dev/null 2>&1; then
    log "✅ orule-server 已就绪"
    break
  fi
  sleep 2
done
[ $i -lt 30 ] || err "orule-server 启动超时（60 秒）"

# 启动 orule-runtime（后台）
log "🟢 启动 orule-runtime（端口 8081）..."
(cd packages/orule-runtime && mvn spring-boot:run) > ~/orule/data/logs/runtime.log 2>&1 &
RUNTIME_PID=$!

log "⏳ 等待 orule-runtime 就绪..."
for i in {1..30}; do
  if curl -s http://localhost:8081/actuator/health > /dev/null 2>&1; then
    log "✅ orule-runtime 已就绪"
    break
  fi
  sleep 2
done
[ $i -lt 30 ] || err "orule-runtime 启动超时（60 秒）"

# 启动 orule-web（如已实现）
if [ -d orule-web ] && [ -f orule-web/package.json ]; then
  log "🟢 启动 orule-web（端口 5173）..."
  (cd orule-web && pnpm dev) > ~/orule/data/logs/web.log 2>&1 &
  WEB_PID=$!
else
  warn "⏭️  orule-web 暂未实现（占位）"
  WEB_PID=""
fi

echo ""
log "✅ 全部服务已启动！"
echo ""
echo "  📘 orule-server:    http://localhost:8080"
echo "  ⚡ orule-runtime:   http://localhost:8081"
echo "  🌐 orule-web:       http://localhost:5173（如已实现）"
echo ""
echo "进程 PID: server=$SERVER_PID, runtime=$RUNTIME_PID, web=$WEB_PID"
echo "日志目录: ~/orule/data/logs/"
echo ""
echo "按 Ctrl+C 停止全部服务..."

# 优雅退出
trap "log '🛑 停止全部服务...'; kill $SERVER_PID $RUNTIME_PID $WEB_PID 2>/dev/null; exit 0" INT TERM
wait
```

### 3.2 Windows（`scripts/dev-start.ps1`）

```powershell
# scripts/dev-start.ps1
# 一键启动 orule 本地一体化开发环境（Windows PowerShell）

$ErrorActionPreference = "Stop"

function Log($msg) { Write-Host "[$(Get-Date -Format 'HH:mm:ss')] $msg" -ForegroundColor Green }
function Warn($msg) { Write-Host "[$(Get-Date -Format 'HH:mm:ss')] $msg" -ForegroundColor Yellow }
function Err($msg) { Write-Host "[$(Get-Date -Format 'HH:mm:ss')] ERROR: $msg" -ForegroundColor Red; exit 1 }

# 检查依赖
if (-not (Get-Command java -ErrorAction SilentlyContinue)) { Err "未找到 java，请安装 JDK 21+" }
if (-not (Get-Command mvn -ErrorAction SilentlyContinue))  { Err "未找到 mvn，请安装 Maven 3.9+" }

Log "🚀 启动 orule 本地一体化开发环境..."

# 创建数据目录
$dataDir = Join-Path $env:USERPROFILE "orule\data"
New-Item -ItemType Directory -Force -Path "$dataDir\db"    | Out-Null
New-Item -ItemType Directory -Force -Path "$dataDir\artifacts" | Out-Null
New-Item -ItemType Directory -Force -Path "$dataDir\logs"  | Out-Null

# 启动 orule-server（后台）
Log "🟢 启动 orule-server（端口 8080）..."
$serverJob = Start-Job -ScriptBlock {
    Set-Location $args[0]
    mvn spring-boot:run
} -ArgumentList "$PSScriptRoot\..\packages\orule-server"

Log "⏳ 等待 orule-server 就绪..."
$serverReady = $false
for ($i = 1; $i -le 30; $i++) {
    Start-Sleep -Seconds 2
    try {
        $response = Invoke-WebRequest -Uri "http://localhost:8080/actuator/health" -UseBasicParsing -TimeoutSec 3
        if ($response.StatusCode -eq 200) {
            $serverReady = $true
            break
        }
    } catch {}
}
if (-not $serverReady) { Err "orule-server 启动超时" }

# 启动 orule-runtime（后台）
Log "🟢 启动 orule-runtime（端口 8081）..."
$runtimeJob = Start-Job -ScriptBlock {
    Set-Location $args[0]
    mvn spring-boot:run
} -ArgumentList "$PSScriptRoot\..\packages\orule-runtime"

Log "⏳ 等待 orule-runtime 就绪..."
$runtimeReady = $false
for ($i = 1; $i -le 30; $i++) {
    Start-Sleep -Seconds 2
    try {
        $response = Invoke-WebRequest -Uri "http://localhost:8081/actuator/health" -UseBasicParsing -TimeoutSec 3
        if ($response.StatusCode -eq 200) {
            $runtimeReady = $true
            break
        }
    } catch {}
}
if (-not $runtimeReady) { Err "orule-runtime 启动超时" }

Write-Host ""
Log "✅ 全部服务已启动！"
Write-Host ""
Write-Host "  📘 orule-server:    http://localhost:8080"
Write-Host "  ⚡ orule-runtime:   http://localhost:8081"
Write-Host ""
Write-Host "按 Ctrl+C 停止..."

# 清理
Register-EngineEvent -SourceIdentifier PowerShell.Exiting -Action {
    Stop-Job -Job $serverJob -PassThru | Remove-Job -Force
    Stop-Job -Job $runtimeJob -PassThru | Remove-Job -Force
}

Wait-Job -Job $serverJob, $runtimeJob
```

### 3.3 Makefile（可选，Linux/macOS）

```makefile
# Makefile
.PHONY: help build server runtime web start stop clean

help:
	@echo "orule 开发命令："
	@echo "  make build    - 编译全部模块"
	@echo "  make server   - 启动 orule-server"
	@echo "  make runtime  - 启动 orule-runtime"
	@echo "  make web      - 启动 orule-web"
	@echo "  make start    - 一键启动全部"
	@echo "  make stop     - 停止全部"
	@echo "  make clean    - 清理构建产物"

build:
	mvn clean install -DskipTests

server:
	cd packages/orule-server && mvn spring-boot:run

runtime:
	cd packages/orule-runtime && mvn spring-boot:run

web:
	cd orule-web && pnpm dev

start:
	./scripts/dev-start.sh

stop:
	@echo "🛑 停止全部服务..."
	@pkill -f 'spring-boot:run' || true

clean:
	mvn clean
	rm -rf orule-web/node_modules orule-web/dist
	rm -rf packages/*/target
```

## 5. 测试计划

| 测试 | 方式 |
|------|------|
| Linux / macOS 启动 | `./scripts/dev-start.sh` 成功 |
| Windows 启动 | `.\scripts\dev-start.ps1` 成功 |
| 健康检查 | `curl /actuator/health` 返回 200 |
| 优雅退出 | Ctrl+C 停止全部进程 |
| 日志输出 | `~/orule/data/logs/server.log` 有内容 |

---

## 6. 风险

- **R1**：跨平台兼容（Windows / macOS / Linux）→ 缓解：分别提供 `.sh` 和 `.ps1`
- **R2**：后台进程管理复杂 → 缓解：使用 PID + trap/Register-EngineEvent
- **R3**：端口被占用 → 缓解：启动前 `lsof -i:8080` 检查

---

