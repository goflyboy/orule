# RFC-0022: 测试用例 + 通过率统计

> **状态**：DRAFT · **优先级**：P0 · **预计工作量**：3d · **阶段**：S5

## 1. 摘要

实现 RuleTestCase CRUD 和批量测试运行，提供通过率统计、失败详情和重跑能力。

---

## 2. 动机

- 测试用例是 NL→SimpleTS→Groovy→执行 链路的验证层（依据 `02-用例视图 §2.4.4`）
- NL 编辑器需要测试用例验证 LLM 生成的 SimpleTS 是否正确（依据 `06-运行视图 §6.1.1`）
- 支撑 MVP 演示的可验证性

    @NotNull Map<String, Object> expectedJson

public record TestRunRequest(
    String ruleId,       // 测单条规则；为空则测所有

public record TestRunResult(
    String ruleId,
    int totalCases,
    int passed,
    int failed,

    List<CaseResult> results

    public record CaseResult(
        String testCaseId, String testCaseName,
        String status,      // PASS / FAIL / ERROR
        String message,
        Map<String, Object> actualOutput,

    ) {}

### 3.3 Service

```java
@Service
@RequiredArgsConstructor
public class TestCaseService {

    private final TestCaseRepository testCaseRepo;
    private final RuleExecutor ruleExecutor;    // orule-runtime HTTP client
    private final RuleRepository ruleRepo;

    // ========== CRUD ==========

    public List<TestCaseDto> findByRuleId(String ruleId) {
        return testCaseRepo.findByRuleIdOrderByCreatedAtAsc(ruleId).stream()
            .map(this::toDto).toList();
    }

    @Transactional
    public TestCaseDto create(CreateTestCaseRequest req) {
        Rule rule = ruleRepo.findById(req.ruleId())
            .orElseThrow(() -> new NotFoundException("Rule", req.ruleId()));
        TestCase tc = TestCase.builder()
            .id(UUID.randomUUID().toString())
            .ruleId(req.ruleId())
            .name(req.name())
            .description(req.description())
            .inputJson(toJson(req.inputJson()))
            .expectedJson(toJson(req.expectedJson()))
            .active(true)
            .build();
        return toDto(testCaseRepo.save(tc));
    }

    @Transactional
    public void delete(String testCaseId) {
        testCaseRepo.deleteById(testCaseId);
    }

    // ========== 批量测试 ==========

    /**
     * 运行规则的所有测试用例。
     * 依据 06-运行视图 §6.1.1 Step 15~17。
     */
    public TestRunResult runRuleTests(String ruleId, boolean async) {
        List<TestCase> cases = testCaseRepo.findByRuleIdAndActiveTrue(ruleId);
        if (cases.isEmpty()) {
            return new TestRunResult(ruleId, 0, 0, 0, 0, List.of());
        }
        
        if (async) {
            // 异步执行，立即返回
            CompletableFuture.runAsync(() -> executeTests(ruleId, cases));
            return null;  // 前端轮询状态
        }
        
        return executeTests(ruleId, cases);
    }

    private TestRunResult executeTests(String ruleId, List<TestCase> cases) {
        List<TestRunResult.CaseResult> results = new CopyOnWriteArrayList<>();
        AtomicInteger passed = new AtomicInteger(0);
        AtomicInteger failed = new AtomicInteger(0);

        cases.parallelStream().forEach(tc -> {
            CaseResult cr = runSingleCase(tc);
            results.add(cr);
            if ("PASS".equals(cr.status())) {
                passed.incrementAndGet();
            } else {
                failed.incrementAndGet();
            }

            // 更新 lastResult
            tc.setLastResult(cr.status());
            tc.setLastRunAt(Instant.now());
            testCaseRepo.save(tc);
        });

        double passRate = cases.isEmpty() ? 0 :
            (double) passed.get() / cases.size() * 100;

        return new TestRunResult(
            ruleId,
            cases.size(),
            passed.get(),
            failed.get(),
            Math.round(passRate * 100.0) / 100.0,
            results.stream().sorted(Comparator.comparing(TestRunResult.CaseResult::status)).toList()
        );
    }

    private TestRunResult.CaseResult runSingleCase(TestCase tc) {
        try {
            long start = System.currentTimeMillis();

            // 调用 orule-runtime 执行规则
            Map<String, Object> input = fromJson(tc.getInputJson());
            ExecutionResult execResult = ruleExecutor.executeRule(
                tc.getRuleId(), input, "TEST");

            long duration = System.currentTimeMillis() - start;

            if (!execResult.success()) {
                return new TestRunResult.CaseResult(
                    tc.getId(), tc.getName(),
                    "ERROR",
                    execResult.errorMessage(),
                    null, duration
                );
            }

            // 比对输出
            Map<String, Object> expected = fromJson(tc.getExpectedJson());
            Map<String, Object> actual = execResult.outputContext();

            boolean pass = compareMaps(expected, actual);

            return new TestRunResult.CaseResult(
                tc.getId(), tc.getName(),
                pass ? "PASS" : "FAIL",
                pass ? null : "输出不匹配: " + diff(expected, actual),
                actual, duration
            );

        } catch (Exception e) {
            return new TestRunResult.CaseResult(
                tc.getId(), tc.getName(),
                "ERROR", e.getMessage(), null, 0
            );
        }
    }

    /**
     * 深度比较两个 Map（支持嵌套）。
     * 数值类型宽容：int 100 vs long 100 视为相等。
     */
    private boolean compareMaps(Map<String, Object> expected, Map<String, Object> actual) {
        for (String key : expected.keySet()) {
            Object expVal = expected.get(key);
            Object actVal = actual.get(key);

            if (expVal instanceof Map && actVal instanceof Map) {
                if (!compareMaps((Map) expVal, (Map) actVal)) return false;
            } else if (!Objects.equals(expVal, actVal)) {
                // 数值类型宽容
                if (expVal instanceof Number && actVal instanceof Number) {
                    double exp = ((Number) expVal).doubleValue();
                    double act = ((Number) actVal).doubleValue();
                    if (Math.abs(exp - act) > 0.001) return false;
                } else {
                    return false;
                }
            }
        }
        return true;
    }

    private String diff(Map<String, Object> expected, Map<String, Object> actual) {
        StringBuilder sb = new StringBuilder();
        for (String key : expected.keySet()) {
            Object exp = expected.get(key);
            Object act = actual.get(key);
            if (!Objects.equals(exp, act)) {
                sb.append(key).append(": 期望 ").append(exp)
                  .append("，实际 ").append(act).append("; ");
            }
        }
        return sb.length() > 0 ? sb.toString() : "未知差异";
    }

    private Map<String, Object> fromJson(String json) {
        try {
            return new ObjectMapper().readValue(json, new TypeReference<>() {});
        } catch (JsonProcessingException e) {
            return Map.of();
        }
    }

    private String toJson(Map<String, Object> map) {
        try {
            return new ObjectMapper().writeValueAsString(map);
        } catch (JsonProcessingException e) {
            return "{}";
        }
    }

    private TestCaseDto toDto(TestCase tc) {
        return new TestCaseDto(
            tc.getId(), tc.getRuleId(), tc.getName(), tc.getDescription(),
            fromJson(tc.getInputJson()), fromJson(tc.getExpectedJson()),
            tc.isActive(), tc.getLastResult(), tc.getLastRunAt(),
            tc.getCreatedAt(), tc.getUpdatedAt()
        );
    }
}
```

## 5. 测试计划

| 测试 | 方式 |
|------|------|
| CRUD | API 验证 |
| 数值宽容 | int 100 vs long 100 通过 |
| 嵌套 Map | `{ order: { discount: 30 } }` 正确比对 |
| 失败详情 | diff 信息正确 |
| 异步轮询 | 前端轮询场景 |
| 并发运行 | parallelStream 并发执行 |
| lastResult 更新 | 每次运行后正确更新 |
