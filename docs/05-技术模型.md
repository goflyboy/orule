## 5.3 服务间通信矩阵

| 调用方 | 被调用方 | 协议 | 说明 |
|--------|----------|------|------|
| `orule-web`（浏览器）→ `orule-server` | REST | HTTP | CRUD / 编译 / 打包 |
| `orule-runtime` → `orule-server` | REST | HTTP | 拉取 RuleArtifact |
| `orule-mcp-server`（Node.js） → `orule-server` | REST | HTTP | MCP 透传 |
| `orule-llm-studio`（Electron） → Cursor/OpenCode | MCP / IPC | - | 调用本地 Agent 环境 |
| `orule-llm-studio`（Electron） → `orule-server` | REST | HTTP（可选） | 拉取规则模板等元数据 |

> **Phase 1 LLM 路径**：Electron → Cursor/OpenCode Agent（MCP 协议）→ LLM（Cursor/OpenCode 内置）
> **Phase 2 LLM 路径**：Electron → 远程 LLM Server（未来独立部署）

## 5.4 orule-llm-studio（Electron）详细设计

### 5.4.1 设计定位

| 维度 | 说明 |
|------|------|
| **是什么** | 独立桌面应用，封装 Cursor/OpenCode 的 LLM 能力，为业务人员提供 NL ↔ SimpleTS 转换 |
| **不是** | 不是浏览器页面；不调服务端 LLM（Phase 1） |
| **优势** | Electron 可以读写本地文件系统、调用本地进程（Cursor/OpenCode MCP Server） |
| **Phase 1** | Electron Main Process 直接调用 Cursor/OpenCode 的 MCP 能力 |
| **Phase 2** | Electron 调远程 `orule-llm` 服务（可选） |

### 5.4.2 进程架构

```
Electron Main Process（Node.js）
  ├── 读写 Cursor/OpenCode 工作空间（文件系统）
  ├── 调用 Cursor/OpenCode MCP Server（子进程 / IPC）
  ├── 管理 Local Server（Express/Fastify，端口 5174）
  │     └── 提供 REST API 给 Renderer（Chat / Convert）
  └── IPC（主进程 ↔ 渲染进程）
        ├── channel: "llm:chat"
        ├── channel: "file:read"
        └── channel: "mcp:call"

Electron Renderer Process（React）
  ├── Chat UI（多轮对话）
  ├── ConvertPanel（NL ↔ SimpleTS 转换按钮）
  └── 调用 Local Server REST API（端口 5174）
```

### 5.4.4 Main Process 示例

```typescript
// electron/main.ts
import { app, ipcMain } from 'electron';
import { spawn } from 'child_process';
import express from 'express';
import { WebSocketServer } from 'ws';

const LOCAL_SERVER_PORT = 5174;
let cursorAgent: ChildProcess | null = null;

// 1. 启动 Cursor/OpenCode Agent（子进程）
function startCursorAgent() {
  // 尝试启动 Cursor MCP Server（假设本地已安装）
  cursorAgent = spawn('cursor', ['--mcp-server'], {
    cwd: process.env.CURSOR_WORKSPACE || app.getPath('home'),
    stdio: ['pipe', 'pipe', 'pipe']
  });
  cursorAgent.stdout?.on('data', (data) => console.log('[Cursor]', data.toString()));
  cursorAgent.stderr?.on('data', (data) => console.error('[Cursor Error]', data.toString()));
}

// 2. 启动本地 Local Server（Express）
function startLocalServer() {
  const app = express();
  app.use(express.json());

  // Chat API（MCP 调用 Cursor/OpenCode）
  app.post('/api/v1/chat', async (req, res) => {
    const { messages } = req.body;
    // 通过 IPC 调用 Cursor/OpenCode LLM
    const result = await callCursorLLM(messages);
    res.json(result);
  });

  // NL → SimpleTS 转换
  app.post('/api/v1/convert/nl-to-simplets', async (req, res) => {
    const { nl } = req.body;
    const result = await convertNLtoSimpleTS(nl);
    res.json(result);
  });

  app.listen(LOCAL_SERVER_PORT, () => {
    console.log(`[LLM Studio Local Server] http://localhost:${LOCAL_SERVER_PORT}`);
  });
}

// 3. IPC 处理（主进程 ↔ 渲染进程）
ipcMain.handle('llm:chat', async (_, messages) => {
  return callCursorLLM(messages);
});

ipcMain.handle('file:read', async (_, path) => {
  const fs = await import('fs/promises');
  return fs.readFile(path, 'utf-8');
});

ipcMain.handle('mcp:call', async (_, { tool, args }) => {
  // 调用 Cursor/OpenCode MCP Server
  return callMcpTool(tool, args);
});

app.whenReady().then(() => {
  startCursorAgent();
  startLocalServer();
});

app.on('window-all-closed', () => {
  cursorAgent?.kill();
  app.quit();
});
```

### 5.6.2 模式二：独立部署（Node.js，端口 3001）

```typescript
// orule-mcp-server/src/server.ts
import { Server } from '@modelcontextprotocol/server';
import { CallToolRequestSchema } from '@modelcontextprotocol/sdk/types.js';
import axios from 'axios';

const ORULE_SERVER = process.env.ORULE_SERVER_URL || 'http://localhost:8080/api/v1';

const server = new Server({ name: 'orule-mcp-server', version: '0.1.0' },
                          { capabilities: { tools: {} } });

server.setRequestHandler(CallToolRequestSchema, async (request) => {
  const { name, arguments: args } = request.params;
  switch (name) {
    case 'rule_create_from_nl': return await axios.post(`${ORULE_SERVER}/rules`, args);
    case 'rule_list':           return await axios.get(`${ORULE_SERVER}/rules`);
    case 'rule_get':            return await axios.get(`${ORULE_SERVER}/rules/${args.ruleSetCode}/${args.ruleCode}`);
    case 'rule_execute':        return await axios.post(`${ORULE_SERVER}/rules/${args.ruleSetCode}/${args.ruleCode}:execute`, args);
    default: throw new Error(`Unknown tool: ${name}`);
  }
});

server.listen(3001);
```

## 5.7 orule-runtime 服务详细设计

### 5.7.1 服务定位

| 维度 | 说明 |
|------|------|
| **核心功能** | 加载 `RuleArtifact`、执行 Groovy 沙箱、写入 `ExecutionLog` |
| **资源特征** | CPU 密集 + 内存敏感（Groovy 类加载） |
| **隔离特性** | groovy-sandbox + 自定义白名单（只执行用户提交的 Groovy 脚本） |
| **触发方式** | `orule-server` 异步调度（编译后自动触发）；orule-web REST 触发（测试执行） |

### 5.7.2 沙箱白名单

> **重要**：orule-runtime 执行用户提交的 Groovy，需要沙箱隔离（与 Cursor/OpenCode 的本地 Agent 环境不同）：

```java
// orule-runtime/infrastructure/sandbox/SimpleTSGroovyWhitelist.java
import org.kohsuke.groovy.sandbox.impl.*;

public class SimpleTSGroovyWhitelist extends InterceptorScope {
    private static final Set<String> ALLOWED = Set.of(
        // Math（SimpleTS §8.1）
        "abs", "min", "max", "floor", "ceil", "round",
        // String
        "length", "startsWith", "endsWith", "includes",
        "toUpperCase", "toLowerCase", "charAt", "substring",
        // Date
        "getFullYear", "getMonth", "getDate"
    );

    @Override
    public Object onMethodCall(Invoker invoker, Object receiver, String method, Object... args)
            throws Throwable {
        if (!ALLOWED.contains(method)) {
            throw new SecurityException("方法 '" + method + "' 不在 SimpleTS 白名单");
        }
        return invoker.onMethodCall(receiver, method, args);
    }
}
```

### 5.7.3 REST API

| Method | Path | 说明 |
|--------|------|------|
| POST | `/api/v1/runtime/execute` | 单条规则执行 |
| POST | `/api/v1/runtime/batch-execute` | 批量执行（多规则集） |
| GET  | `/api/v1/runtime/executions/{id}` | 查询执行结果 |

### 5.7.4 主流程

```java
// orule-runtime/application/ExecutionService.java
@Service
public class ExecutionService {
    @Autowired private RemoteArtifactLoader loader;
    @Autowired private GroovySandboxExecutor groovyExecutor;
    @Autowired private ExecutionRepository executionRepo;

    public ExecutionResult execute(ExecutionRequest req) {
        // 1. 加载 RuleArtifact（从 orule-server 拉取）
        CompiledArtifact artifact = loader.load(req.getRuleId(), req.getVersion());

        // 2. 沙箱执行
        ExecutionResult result;
        switch (artifact.getEngineType()) {
            case GROOVY:
                result = groovyExecutor.execute(artifact.getCompiledCode(), req.getFacts());
                break;
            case CRULEENGINE:
                result = cruleEngineAdapter.execute(artifact.getCompiledCode(), req.getFacts());
                break;
            default:
                throw new UnsupportedOperationException("Engine: " + artifact.getEngineType());
        }

        // 3. 记录 Execution + ExecutionLog
        executionRepo.save(result.toExecution());
        return result;
    }
}
```
